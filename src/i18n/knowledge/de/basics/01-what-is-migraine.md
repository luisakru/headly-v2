# 🧠 Was ist Migräne?

Migräne ist eine neurologische Erkrankung, kein „normaler“ Kopfschmerz. Etwa jede siebte Person hat sie, Frauen rund dreimal so oft wie Männer.

Eine Attacke dauert unbehandelt 4 bis 72 Stunden. Der Schmerz ist oft einseitig, pochend und wird bei Bewegung schlimmer.

Dazu kommen meist Übelkeit oder Empfindlichkeit gegen Licht und Geräusche. Deshalb ist Headly so ruhig und dunkel gehalten.
